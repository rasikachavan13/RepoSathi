# Contributing to RepoSathi AI

Thanks for your interest in contributing!

## Before you start

1. Read the README and understand the current behaviour.
2. For a larger change, open an issue or discuss the idea first.
3. Never include API keys, passwords, private repository content, or other secrets in an issue or pull request.

## Development

```bash
npm install
npm run server
```

In a second terminal:

```bash
npm run dev
```

## Pull request checklist

- [ ] The change has a clear, focused purpose.
- [ ] The UI works on mobile and desktop where relevant.
- [ ] Error and loading states are handled.
- [ ] No secrets or private user content are committed.
- [ ] README or relevant documentation is updated.
- [ ] I tested the change locally.

Please keep first contributions small and respectful. Questions are welcome.
